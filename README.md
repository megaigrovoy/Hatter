# Hatter (Web MediaPipe)

Игра для веб-камеры на той же технологии, что и [Blasters](https://github.com/megaigrovoy/Blasters):
MediaPipe Pose Landmarker + canvas поверх видео, Vite, без бэкенда.

**Суть:** сверху планируют шляпы. Нужно успеть подставить под шляпу голову — тогда она
надевается и остаётся на голове до тех пор, пока игрок не поймает следующую.

## Правила

- Шляпа планирует сверху, покачиваясь как лист. Подставь под неё макушку.
- Попадание засчитывается только по центру головы. Заденешь краем — шляпа
  отлетает в сторону, кувыркается и падает мимо.
- Пойманная шляпа надевается и держится на голове, следуя наклону, пока игрок
  не поймает следующую.
- Жизней нет. Пропущенная шляпа ничего не отнимает, только обрывает серию,
  поэтому уровень всегда доигрывается до конца.
- Чёрный цилиндр с красным крестом — ловушка. Пойманная головой, она сбивает
  надетую шляпу и обрывает серию. Пусть падает мимо.
- Золотая шляпа даёт 150 очков вместо обычных 45–70.
- Серия подряд пойманных шляп добавляет к очкам до +50.
- Уровень засчитан за 40 пойманных шляп. Уровней пять: с каждым шляпы летят
  быстрее, появляются чаще и растёт доля ловушек.

## Управление

Управление только телом. Голова отслеживается по ушам и носу: линия ушей задаёт угол посадки
шляпы и её размер. Пока шляпы нет, над макушкой пульсирует круг с перекрестьем — это зона
точного попадания, куда надо подвести центр шляпы.

## Режимы

- **1 игрок** — сольный забег.
- **2 игрока** — оба перед одной камерой, счёт общий, у каждого своя шляпа на голове.

Переключатель в меню сохраняется и перезапускает модель поз (`numPoses`).

## Запуск

```bash
npm install
npm run dev
```

Открыть HTTPS URL из терминала. Камера требует безопасный контекст, поэтому дев-сервер
поднимается с самоподписанным сертификатом (`@vitejs/plugin-basic-ssl`).

## Сборка

```bash
npm run build
```

`npm run prepare:wasm` копирует WASM MediaPipe в `public/mediapipe-wasm`, чтобы модель грузилась
со своего домена. Если файл недоступен, код падает обратно на CDN jsDelivr.

## Технические заметки

- **Трекинг.** `pose_landmarker_lite`, делегат GPU на десктопе и iPad, CPU-первым на Android:
  там GPU-делегат даёт нестабильные landmarks.
- **Плавность.** Landmarks сглаживаются экспоненциально (лицо мягче тела), а между кадрами
  камеры позиции интерполируются — на экране 120 Гц шляпа не дёргается при 30 fps камеры.
- **Стабильность игроков.** `Pose#0` и `Pose#1` закреплены за людьми по центру плеч, а не по
  порядку выдачи модели. Надетая шляпа не перепрыгивает на соседа, если игрок на миг пропал.
- **Графика.** Шесть шляп — PNG-спрайты 512×512 в `src/assets/img/hats`. Для каждой
  задана линия посадки (`seatYFrac`) и доля ширины, которую занимает рисунок
  (`artWidthFrac`): без них шляпы разной вёрстки сидели бы на разной высоте.
  Золотая шляпа и ловушка рисуются процедурно, чтобы читаться как особые.
- **Звук.** Эффекты и фоновый арпеджиатор синтезируются в Web Audio, аудиофайлов в репозитории нет.
  Контекст разблокируется в пользовательском жесте — иначе iOS оставляет его немым.
- **Канвас** зеркалится по X, поэтому текст очков рисуется с обратным масштабом.
- Буфер канваса ограничен 1280 px по длинной стороне: на больших экранах это экономит GPU и CPU.

Отладка производительности: добавьте `?perf=1` к URL, среднее время кадра пойдёт в консоль.
